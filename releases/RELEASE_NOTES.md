# ✦ Fish an Anime RNG · Release v4.8

## 🎃 Hell's Gates is really ignored now
* v4.7 looked for exact words of the Hell's Gates banner, but the OCR often reads them wrong ("Getes", "Fdting", "OLOOD"), so the event character could still come out.
* The Hell's Gates check now accepts these misreads. Tested on every event banner the macro logged: all Hell's Gates are ignored and every Hallows Eve is still detected.

## 📦 Download

**[FAA-Macro-v4.8.zip](FAA-Macro-v4.8.zip)**: unzip anywhere, then double-click `START_MACRO.bat` (it installs AutoHotkey v2 if needed). If you already have v4.4 or later, the macro offers to update itself on launch.
